# Portfolio Studio — Hər Peşəyə Uyğun Portfolio Nümunələri

Dizayner, proqramçı, fotoqraf və SMM mütəxəssisi üçün 4 fərqli üslubda hazır portfolio demo səhifəsi və onları təqdim edən əsas vitrin səhifəsi.

## Fayllar

| Fayl | Təsvir |
|---|---|
| `index.html` | Əsas səhifə — bütün nümunələrin vitrini, xidmət təqdimatı və əlaqə |
| `dizayner.html` | Qrafik Dizayner portfoliosu (açıq, yaradıcı üslub) |
| `developer.html` | Full-Stack Developer portfoliosu (terminal/dark üslub) |
| `fotoqraf.html` | Fotoqraf portfoliosu (elegant dark + qızılı üslub, qiymət paketləri ilə) |
| `smm.html` | SMM Mütəxəssisi portfoliosu (keys nəticələri və statistika ilə) |

Heç bir asılılıq yoxdur — təmiz HTML/CSS, xarici kitabxana və şəkil istifadə olunmayıb (bütün vizuallar CSS gradient-lərlə qurulub, ona görə hər yerdə sürətli açılır).

## Vercel-ə yükləmə

1. [vercel.com](https://vercel.com) hesabınıza daxil olun.
2. **Add New → Project** seçin və bu GitHub repozitoriyasını (`portfolionumuneleri`) import edin.
3. Heç bir build ayarı lazım deyil (statik sayt) — **Deploy** düyməsini basın.
4. 30 saniyəyə saytınız `https://portfolionumuneleri.vercel.app` kimi ünvanda hazır olacaq.

Alternativ: Vercel CLI ilə — qovluqda `npx vercel --prod` əmrini icra edin.
